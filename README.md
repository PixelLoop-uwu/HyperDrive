# HyperDrive

HyperDrive — это веб-приложение для управления и хранения файлов, работающее как облачное хранилище (подобно Google Drive).

## О проекте

Приложение состоит из двух частей:

- **Backend** — REST API на Python (FastAPI) с аутентификацией, управлением пользователями и файлами
- **Frontend** — интерактивный веб-интерфейс на React + TypeScript с функциями для работы с файлами

## Основные возможности

- 🔐 Аутентификация и авторизация с JWT
- 📁 Управление файлами и папками (создание, удаление, перемещение)
- 🗑️ Корзина для восстановления удалённых файлов
- 👥 Профили пользователей с сессиями
- 🎨 Современный и удобный интерфейс на React

## Стек технологий

**Backend:**
- Python 3.11+
- FastAPI
- SQLAlchemy (ORM)
- PostgreSQL

**Frontend:**
- React 18+
- TypeScript
- TailwindCSS
- Vite
- React Query

## Структура проекта

```
/backend  — серверная часть (API)
/frontend — клиентская часть (веб-интерфейс)
```
